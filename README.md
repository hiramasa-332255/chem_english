# chem_english
化学英語 復習単語帳
====================

【使い方】
1．chemistry_english_review.xlsx に単語を追加して保存します．
2．start_flashcards.bat をダブルクリックします．
3．ブラウザが開き，HTMLと同じフォルダのExcelが自動で読み込まれます．

【Excel更新後】
Excelを上書き保存してからブラウザを再読み込みしてください．
HTMLを編集したり，再作成したりする必要はありません．

【ファイル名】
Excelのファイル名は chemistry_english_review.xlsx のままにしてください．
「復習単語」シートの「英単語・表現」「日本語訳」「収録理由」を読み込みます．

【終了方法】
最小化されている「Chemistry Flashcards Server」ウィンドウを閉じると停止します．

【補足】
HTMLを直接ダブルクリックすると，ブラウザの安全制限によってExcelを読み込めない
ことがあります．必ず start_flashcards.bat または VS CodeのLive Serverから開いてください．
